## 🚀 Systems I've Built

<table>
<tr>
<td width="50%" valign="top">

<h3 align="center">
<a href="https://github.com/AmruthAmruth/Speedo">Speedo</a>
</h3>

<p align="center">
<strong>Live GPS Fleet Analytics</strong>
</p>

<p>
High-frequency GPS events enter a BullMQ queue, where a streaming Haversine pass computes distance, speed, idling, and stoppages. Socket.IO publishes trip updates while the vehicle is still moving.
</p>

<p>
The streaming path reduced processing latency by <strong>70%</strong>, while a single trip can handle <strong>200+ GPS points</strong> without blocking the API.
</p>

<p align="center">
<code>Node.js</code>
<code>TypeScript</code>
<code>BullMQ</code>
<code>Redis</code>
<code>Socket.IO</code>
</p>

</td>

<td width="50%" valign="top">

<h3 align="center">
<a href="https://github.com/AmruthAmruth/Stratify">Stratify</a>
</h3>

<p align="center">
<strong>Multi-Tenant Company Platform</strong>
</p>

<p>
One backend serves company, manager, employee, and super-admin surfaces with tenant isolation across data, sessions, and configuration.
</p>

<p>
Clean Architecture and TSyringe keep the domain independent of the framework. Zod validates inputs, RBAC protects routes, and MongoDB transactions commit related writes atomically.
</p>
